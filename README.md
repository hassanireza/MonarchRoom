# 🃏 Monarch Room
![MonarchRoom Screenshot](./assets/MonarchRoom.png)

> Private Texas Hold’em Poker Game

Monarch Room is a sleek, browser-based Texas Hold’em poker experience built with pure JavaScript. It combines realistic gameplay mechanics, intelligent AI opponents, and a refined casino-style interface to deliver a premium single-player poker experience.

---

## ✨ Features

* 🧠 **AI Opponents**
  Unique personalities and decision-making styles

* 🎮 **Tournament Mode**
  Play until one player takes all the chips

* 💰 **Real Poker Mechanics**
  Blinds, betting rounds, all-ins, and hand evaluation

* 📊 **Stats & Leaderboard**
  Track performance across hands and tournaments

* 🎨 **Premium UI/UX**
  Smooth animations, clean layout, and immersive design

* ⚡ **Fast & Lightweight**
  No frameworks — built with vanilla JavaScript

---

## 🛠 Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript (ES6)

---

## 🎯 Gameplay

* Start a tournament with multiple AI players
* Progress through:

  * Preflop
  * Flop
  * Turn
  * River
* Make decisions:

  * Fold
  * Call
  * Raise
  * All-in
* Eliminate opponents and become the last player standing

---

## 🧠 AI System

Each opponent has:

* Play style (tight, aggressive, loose)
* Confidence evaluation
* Situational decision logic

This creates dynamic and unpredictable gameplay.
